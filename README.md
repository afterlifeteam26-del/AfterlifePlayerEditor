## Overview

Afterlife Player Editor is a Windows desktop administration application designed for authorized SCUM dedicated server owners and administrators.

The application provides a modern, centralized interface for managing player skills, experience and character attributes in real time, without stopping the game server or directly modifying its live database.

Built with usability, reliability, security and performance in mind, Afterlife Player Editor simplifies player administration while maintaining control over server-side changes.

## Features

### Live Player Management
- View connected players in real time.
- Search players by name or Steam ID.
- Edit individual or multiple player skills.
- Modify skill levels and experience points.
- Manage character strength, constitution, dexterity and intelligence.
- Verify player changes through live server readback.
- Perform supported player edits without restarting the server.

### Dashboard
- Real-time server connection status.
- Online player count and peak session population.
- Server request latency monitoring.
- Automatic player roster refresh.
- Connection-based session timer.
- Recent activity and edit statistics.

### Edit History
- Persistent player modification history.
- Original, requested and verified value tracking.
- Player identification and timestamp recording.
- Searchable historical records.
- CSV export for administrative recordkeeping.

### Connection Management
- Secure SFTP connectivity.
- Multiple server profiles.
- Secure Windows credential storage.
- Automatic connection health monitoring.
- Automatic reconnection support.
- Protection against unintended replay of player modifications.

### User Experience
- Modern and responsive Windows interface.
- Customizable application themes.
- Adjustable accent colors and font sizes.
- Collapsible navigation sidebar.
- Persistent appearance preferences.
- Integrated application update system.

### Security & Reliability
- SSH host verification.
- Player edit validation.
- Connection-aware editing restrictions.
- Privacy-conscious local crash reporting.
- SHA-256 update integrity verification.
- Optional digital code-signing support.
- No automatic transmission of crash reports.

## System Requirements

### Client Requirements
- Windows 10 or Windows
